📡 1. Connection & Device Management

BLE Scanning

Discover nearby MeshCore nodes via Bluetooth. Tap any device in the list to connect.

Auto-Reconnect

The last connected BLE address is saved. The app reconnects automatically on next launch.

Foreground Service

A persistent background service keeps the link alive and delivers notifications while the app is minimised.

Clean Disconnect

Tap the disconnect button to close the BLE link and return to the scan screen.

💬 2. Public Channel Chat

The Channel tab shows the shared public mesh channel — all nodes within range can read and send.

  • Chat bubbles: your messages right-aligned, others left-aligned
  • Each bubble shows sender name, timestamp, SNR (dB), and hop count
  • Long-press a received message to add an emoji reaction
  • Swipe right to quote-reply
  • Nearby-node strip at the top shows recent advertisements
  • 160-character limit with live counter
  • Draft text saved automatically if you navigate away

# 3. Private Channels

The Channels tab lists all configured private channels (slots 1–7).

AES-128 Encryption

Each channel uses a unique 128-bit symmetric key. Only nodes with the key can decrypt messages.

Create & Manage

Create a channel with a name and auto-generated key, or supply your own. Update or delete channels at any time.

QR Code Sharing

Share a channel via QR code. Scanning it opens a join dialog in Meshi using the meshichan:// deep link.

Utilisation Graph

Tap the bar-chart icon in any channel chat to see a 24-hour histogram of message activity.

🔒 4. Direct Messaging

One-to-one private messages encrypted with the recipient's public key.

Delivery Receipts

Single tick ✓ = sent. Double tick ✓✓ = confirmed delivered. RTT shown beside the double tick.

Typing Indicators

"typing…" appears in the contact header when the other person is composing a message.

SNR Trend Graph

A sparkline chart shows received signal strength over recent messages. Tap the signal-bars icon to show/hide.

Ping

Tap the ping icon in the DM top bar to measure round-trip latency. Result appears in a snackbar.

Emoji Reactions

Long-press any received message to react. Reactions are delivered to the sender over the mesh.

Quote Reply

Swipe right on any message to inline-quote it in your reply.

✨ 5. Message Features

Swipe-to-Reply / Quote

Swipe any bubble rightward to pre-fill the input with a quoted excerpt.

Emoji Reactions

Long-press a received message to choose from 👍 ❤️ 😂 😮 😢 👎. Reactions are sent over the mesh and displayed as pill chips beneath the bubble, aggregated with a count when multiple people react.

Message Search

Tap the search icon in any chat top bar. Results filter in real time against the full message history stored in the local database.

Message Export

Tap the share icon to export the full chat as plain text via the system share sheet.

Draft Persistence

Unsent text is saved per-conversation and restored when you return — even across app restarts.

Character Counter

A live counter (160-char limit) appears below the input field as you type, turning red near the limit.

👤 6. Contacts & Node Discovery

Nodes Tab

Lists all contacts the app has observed via advertisements or direct message, with their signal, hop count, and last-seen time.

Save Contact

Persist a contact to the local database so it survives reconnects and app restarts.

Nicknames

Override a node's broadcast name with a friendly label that appears everywhere in the app.

Tags

Assign a short tag (e.g. "Team A") and use tag filter chips to quickly view a subset of contacts.

Verified Badge

Mark a contact as verified after confirming their identity. A blue shield appears in chat and on the card.

Block List

Block contacts to silently drop all their future messages before they reach the database.

Backup & Restore

Export all nicknames, tags, and verified flags to JSON. Restore from a backup file on any device.

🗺️ 7. Map

The Map tab plots all nodes that have broadcast GPS coordinates.

  • Each node is shown as a named marker
  • Tap a marker for name, short ID, and coordinates
  • Your own position shown when location sharing is enabled
  • Updates automatically as new GPS-tagged advertisements arrive

📶 8. Advertising & Location

One-Shot Advertise

Tap the tower icon to broadcast your name, node ID, and current GPS coordinates to nearby nodes.

Persistent Location Sharing

Toggle the location pin to automatically include GPS in every outgoing advertisement. Icon turns blue when active.

SOS Beacon

Sends a flood advertisement every 30 seconds. Button turns red when active. Use in emergencies.

Stealth Mode

Suppresses all outgoing advertisements while still allowing message receipt. Icon shows a crossed eye when active.

🛡️ 9. Privacy & Security

Block List

Blocked contacts' messages are dropped at the repository layer — they never reach the database. Manage from the Nodes tab or Settings.

Stealth Mode

No outgoing advertisements means other nodes cannot detect your presence on the mesh.

Private Channel Encryption

128-bit AES symmetric key per channel. Only nodes with the key can decrypt messages.

Direct Message Encryption

DMs are encrypted with the recipient's public key. Only the intended recipient can decrypt.

Panic Wipe

⚠️ Irreversible — permanently deletes all messages, contacts, nicknames, game records, and settings. Closes the BLE connection and returns to the scan screen.

🔔 10. Notifications & Background Service

Incoming Message Notifications

High-priority notifications for new DMs and channel messages. Configurable per message type in Settings.

Quick Reply

Reply inline from the notification shade without opening the app. The notification dismisses itself after sending.

Battery Low Alert

Monitors the node's battery every 5 minutes. Fires a high-priority alert when it drops below the configured threshold.

Foreground Service

A persistent status notification ("Meshi — Connected") keeps the service alive. Low-priority and non-dismissible.

🎮 11. Games

All games are played peer-to-peer over the mesh via DM messages. Challenge any contact from the Nodes tab. Game history is tracked and visible in Settings → Game History.

♟ Reversi

Classic 8×8 Othello. Valid moves highlighted. Game ends when neither player can move.

♜ Chess

Full chess with move validation, check detection, castling, en passant, and pawn promotion.

⊞ Tic-Tac-Toe

Fast 3×3 grid game. Ideal for low-signal conditions — minimal bandwidth required.

⚓ Battleship

10×10 grid, 5 ships. Two-phase: place your fleet, then take turns calling shots. Win/loss and sunk state tracked.

📊 12. Diagnostics & Stats

Node Info

Firmware version, hardware model, battery %, free storage. Tap the ℹ icon in the Channel top bar.

Radio Stats

TX power, frequency, bandwidth, spreading factor, coding rate for the connected radio.

SNR Trend Graph

Sparkline of received SNR (dB) over recent DM messages. Tap the signal icon in the DM top bar.

Channel Utilisation

24-hour bar chart of messages per hour. Tap the bar-chart icon in any chat top bar.

Ping / Latency

Send a latency probe and see the RTT. Available via the ping icon in DM top bar or the Ping button on contact cards.

Crash Log

Most recent unhandled exception stack trace. Accessible from Settings → Debug → Crash Log.
